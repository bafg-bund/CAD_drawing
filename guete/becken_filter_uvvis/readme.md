# Basin holding water quality sensors + filter plate + uv_vis sensor

![Project Status](https://img.shields.io/badge/Status-Prototype-yellow)


This repository contains the construction drawings, CAD models for a multi purpose water basin. The water basin can hold sereral water quality sensors and devices. The repository contains each part as well as the assembly and construciton drawings

This device is designed to stand in a measurement station and be connected to an activly pumped river water line. The water is discharge via a free flow drain.
The construction material should be PVC or on our usecase black PE. This type is mainly used at environmental radiology monitoring stations.
The basin can hold water quality sensors (eg. WTW Temp, pH, o2,..), a filter plate (e.g. Hach Lange 0.2µm) and a UV_Vis sensor which needs constant flow.
